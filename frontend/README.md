# Journal React — альтернативный фронтенд электронного дневника (v1.3)

Кастомный фронтенд для журнала **journal.top-academy.ru**, работающий на официальных API
(`msapi.top-academy.ru/api/v2`) и полностью переписанный с нуля.

```
React 18 · Vite 5 · JavaScript · Tailwind CSS 3 · CSS-переменные
Lucide React (иконки) · Apache ECharts + echarts-for-react (графики, модульная сборка)
React Router 6 (маршрутизация) · TanStack Query 5 (загрузка, кеш, persist)
PWA (manifest + service worker) · Web Notifications · экспорт .ics / CSV
```

## Безопасность — важно прочитать

- **Токены сессии лежат в `localStorage`.** Для локального приложения это приемлемо, но
  любой XSS-скрипт на странице мог бы их прочитать. Не запускайте приложение на чужих
  компьютерах. Если когда-нибудь выкладывать сайт в интернет — токены нужно переносить
  в httpOnly-cookie через собственный бэкенд-прокси.
- **`vite preview` — не production-сервер.** Прокси живёт в Vite-плагине, поэтому для
  постоянного хостинга нужен маленький Node/Express-сервис (или Cloudflare Worker)
  с той же логикой h2/h1 из `vite.config.js`.
- **Прокси ограничен**: только пути `/api/v2/*`, только localhost, чужой `Host` → 403.
  Если нужно пускать запросы из локальной сети (`npm run dev -- --host`), добавьте
  свой адрес в `PROXY_EXTRA_HOSTS` (см. `.env.example`).
- **`application_key` — не секрет** (он публично зашит в бандл оригинального сайта),
  но вынесен в `.env` (`VITE_APPLICATION_KEY`), чтобы не редактировать код.

## Что нужно скачать для запуска

1. **Node.js LTS (версия 18 или новее, лучше 20/22)** — это всё, что нужно.
   Скачивается с официального сайта: <https://nodejs.org/> (при установке ничего менять не нужно,
   npm входит в комплект).
2. Проверить после установки (Win+R → `cmd`, либо любой терминал):
   ```bash
   node -v
   npm -v
   ```

Больше ничего скачивать не надо: все библиотеки ставятся одной командой из пакета.

## Как запустить

```bash
# 1. Распакуйте архив в любую папку
# 2. Откройте терминал в этой папке (в Windows: Shift+ПКМ по папке → «Открыть окно PowerShell»)
# 3. Установите зависимости (один раз, ~1 минута):
npm install

# 4. Запустите приложение:
npm run dev
```

После этого откройте в браузере: **http://localhost:5173** и войдите под своим логином журнала.

### Вариант «как продакшн» (опционально)

```bash
npm run build      # соберёт оптимизированную версию в папку dist
npm run preview    # запустит её на http://localhost:4173
```

Обе команды (`dev` и `preview`) поднимают локальный прокси к API — CORS и DDoS-Guard обходятся автоматически.

## Как это работает внутри

Оригинальный сайт закрыт DDoS-Guard, а его API отдаёт CORS-заголовок только для своего домена.
Поэтому Vite поднимает локальный прокси `/api/v2 → msapi.top-academy.ru` (см. `vite.config.js`):

- данные идут по **HTTP/2** (`node:http2`) — DDoS-Guard его пропускает;
- `/auth/login` и `/auth/refresh` идут по **HTTP/1.1** (`node:https`) — по-другому их режет;
- при блокировке одного транспорта автоматически пробуется второй.

Токены хранятся только в `localStorage` вашего браузера, access-токен обновляется автоматически.
Кеш запросов сохраняется в localStorage (`journal.rq-cache`) — приложение открывается мгновенно.

## Частые вопросы

**Вход не проходит / «Не удалось войти»**
Проверьте логин-пароль на оригинальном сайте. Если сайт сам не работает — и здесь не заработает.
Прокси иногда может поймать проверку DDoS-Guard — просто повторите попытку через минуту.

**Данные пропали после перезапуска**
Сессия живёт в localStorage браузера. Токен доступа обновляется сам; если истёк refresh-токен — просто войдите заново.

**Хочу скрыть лишние вкладки**
Настройки → «Пункты меню» — снимите галочки у ненужных разделов.

**Сдача ДЗ не проходит**
Проверьте, что файл не открыт в другой программе, а комментарий или файл заполнены.
Формат запроса — тот же, что у оригинального сайта (`/homework/operations/create`, multipart).

**Автооценка безопасна?**
Оценка отправляется тем же запросом, каким оригинальный сайт отправляет вашу ручную оценку занятия
(`/feedback/students/evaluate-lesson`). Безопасная версия: автоматически ставятся только оценки 4–5,
не раньше чем через 30 минут после конца пары; теги — из официального справочника `/public/tags`;
одно занятие оценивается ровно один раз; есть режим «по подтверждению», где ничего не уходит без
вашего нажатия; всё можно выключить в настройках в любой момент.

**Почему напоминания не приходят?**
Уведомления включаются в настройках и требуют разрешения браузера. Если вы один раз нажали
«Заблокировать» — нужно снять запрет в настройках сайта (иконка замка в адресной строке).
Напоминания приходят, пока открыта вкладка приложения.
